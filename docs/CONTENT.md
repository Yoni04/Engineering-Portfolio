# Portfolio content and sources

The portfolio is complete using the existing project content, photographs, CAD
renders, and updated public/Yonatan Konstantine Resume.pdf. Additional reports,
measurements, repositories, or demonstrations are not required for this version.

## Project presentation

Each project leads with four concise sections: Overview, My Contributions,
Technical Highlights, and Outcome. The presentation fields in
src/data/projects.ts hold the recruiter-facing summaries.

Detailed contributions, requirements, architecture, development, testing,
challenges, and outcomes are retained under Additional technical notes. The
photographs, system diagrams, galleries, and existing visual design are preserved.
Authoring reminders and promises of future documentation have been removed.

## Source boundaries

Early Bird content is supported by the updated r?sum? and existing project
materials: STM32/Arduino development, approximately 40 kHz transducers, MOSFET
switching, hardware iterations, resonant drive tuning, circuit/acoustic testing,
360-degree directivity measurements. The owner clarified that teammates performed
the SolidWorks modeling and ANSYS simulations, while he observed. Those tools are
not personal skills or hands-on contributions and are attributed to teammates
where the project notes discuss them. This clarification takes precedence over
the broader wording in the résumé.

SMARTZLE content is supported by the r?sum? and existing project materials:
Arduino Nano, GPIO expansion, conductive pieces, LCD feedback, hardware/software
integration, and sustainable educational product design.

The site states these supported activities and outcomes without inventing test
values, team responsibilities, or additional accomplishments. Only existing
images and the r?sum? are offered as project materials. Original PNG and TTF
files are retained; the live site uses compressed WebP images and WOFF2 fonts.
